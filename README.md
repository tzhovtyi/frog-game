# frog game

A small quiz game. You answer a question and the frog jumps to the next lilypad. Five right answers and it gets to the finish.

There are 6 question packs (easy, ЧГК, encyclopedia, riddles, international relations, memes) and 5 frogs you can choose from.

To play just open index.html in the browser.

Animations are done with anime.js.
